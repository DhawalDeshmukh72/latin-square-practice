# Latin Square Practice Platform (DMAT / DLR Test Format)

An interactive, high-fidelity web application designed for pilot aptitude (DLR / DMAT) and cognitive reasoning test practice.

![Latin Square Practice Preview](https://img.shields.io/badge/Test%20Format-DLR%20%2F%20DMAT-blue?style=for-the-badge)
![Status-Live-green](https://img.shields.io/badge/Status-Active-brightgreen?style=for-the-badge)

## 🎯 Features

- **Accurate Test Replication**: Features the standard "Square" grid and "Answer column" layout used in European airline and cadet pilot testing.
- **Infinite Smart Puzzle Generator**: Generates valid Latin Squares with unique solutions on the fly.
- **Multiple Grid Sizes**: Practice $4\times4$ (A–D), $5\times5$ (A–E), or $6\times6$ (A–F).
- **Difficulty Levels**: Easy (1-step deduction), Medium, Hard, and Expert.
- **Practice & Exam Modes**: Free practice with instant feedback or timed exam simulations with score reports.
- **Step-by-Step Logic Explainer**: Demonstrates exact deduction steps with interactive row/column highlighting.
- **Keyboard Shortcuts**: Use keys `A`–`E` to answer, `Space` for the next question, `H` for step-by-step hints.
- **Offline & Zero Dependency**: Built purely with vanilla HTML5, CSS3, and JavaScript with Web Audio synthesized sound effects.

## 🛠️ Local Development

Simply open `index.html` in any web browser, or serve it using Python:

```bash
python3 -m http.server 8080
```
